Reproducible code associated with the following manuscript, which is under review with *Environmetrics*:

E. Lawler and B. Shaby (2026). Bayesian model averaging of risk set probabilities using a geometric representation of multivariate extremes. arXiv:2608.28888. https://doi.org/10.48550/arXiv.2608.28888

## Method overview

The joint distribution of a bivariate extreme is decomposed into radial (R) and 
angular (W) components using a gauge function g(·):

- **Radial model:** R | W ~ Gamma(2, g(W)) above a 95th-quantile threshold, fit 
  via adaptive Metropolis-Hastings MCMC using the `gaugeDependence` Rcpp package.
- **Angular model:** W is modelled either via a star-shaped density (Rcpp) or a 
  mixture of Betas (NIMBLE stick-breaking prior).
- **Six gauge families:** Gaussian, logistic, inverse logistic, asymmetric 
  logistic, Dirichlet, rectangular.
- **Model averaging:** `loo` package stacking / pseudo-BMA weights.
- **Competitor methods:** BezELS (`BezELS` package) and the Campbell-Wadsworth 
  piecewise-linear gauge model (`PWLExtremes` package).
- **Real data marginal transformation:** Raw ERC and FWI observations are 
  transformed to standard exponential margins via a fitted EGPD mixture model 
  in Stan (`cmdstanr`). This step is a prerequisite for all real data analyses.

## Analysis pipeline

### Step 0 — Real data: marginal transformation (Stan)

Before fitting the main model to the fire weather data, ERC and FWI observations 
at each station are transformed to standard exponential margins. This uses the 
Stan models in `samplers/stan/marg_transform/` via `cmdstanr` and only needs to 
be run once. The raw data is prepared by `data_analyses/firefamilydata.R` (reads 
FireFamily Plus CSV exports; local paths will need updating). Outputs are the 
`{station}_expo.qs` files in `data/raw/`.

---

### Steps 1–5: Simulation study

#### Step 1 — Simulate data
```r
Rscript data/sim_200_datasets.R
```
Generates 1800 datasets (200 × 3 dependence structures × 3 dependence levels) 
into `data/{dep_type}/`. Structures: Gaussian copula, logistic, 
Husler-Reiss. Levels: low, mid, high.

#### Step 2 — Run MCMC samplers
Via shell scripts (see `shell_scripts/`):
```bash
bash shell_scripts/run_radial_mcmc.sh        # Rcpp: radial model
bash shell_scripts/run_angle_star_mcmc.sh    # Rcpp: star angular model
bash shell_scripts/run_angle_mix_mcmc.sh     # NIMBLE: mixture angular model
bash shell_scripts/run_bezels_mcmc.sh        # BezELS competitor
# Campbell-Wadsworth: bash shell_scripts/run_cw_fit_and_pred.sh
```

#### Step 3 — Compute pointwise log-likelihoods (for LOO-CV, used in BMA weight calculations)
```bash
bash shell_scripts/run_radial_loglik_calc.sh
bash shell_scripts/run_angle_star_loglik_calc.sh
bash shell_scripts/run_angle_mix_loglik_calc.sh
```

#### Step 4 — Extract BMA weights and posterior parameters
```bash
bash shell_scripts/run_joint_model_wts.sh         # Sim study weights
bash shell_scripts/run_joint_param_extraction.sh  # Posterior parameter summaries
```
Then merge the per-dataset both-angular weights:
```r
Rscript extraction_scripts/merge_wts_both_ang.R
```

#### Step 5 — Compute predictions and generate comparison figures
```r
source("sim_study/imp_samp_preds.R")           # Main gauge model predictions
source("sim_study/bezels_preds.R")             # BezELS predictions
source("sim_study/reshape_cw_preds.R")         # Campbell-Wadsworth predictions
source("sim_study/combine_ls_to_others.R")     # Combined comparison figures
```

---

### Steps 6–7: Real data application

#### Step 6 — Run MCMC on real data
See `shell_scripts/local_machine/` for execution scripts. Runs the same Rcpp and 
NIMBLE samplers as the simulation study, plus BezELS, on the `{station}_expo.qs` 
data from Step 0.

#### Step 7 — Real data analysis and figures
```r
source("data_analyses/posterior_marg_transform.R")    # Marginal model figures
source("data_analyses/diag_plots.R")                  # PP/QQ diagnostics
source("data_analyses/posterior_ang_dens.R")          # Angular density figures
source("data_analyses/level_sets_real_data.R")        # Level set figures
source("data_analyses/imp_samp_real_data_all_iter.R") # Full-posterior predictions
source("data_analyses/return_curve.R")                # Return-level curves
```

### Real-data pipeline ordering

Three steps in the real-data analysis must run in order, because each writes a
file the next one reads:

1. `data_analyses/posterior_marg_transform.R` — transforms ERC/FWI to
   exponential margins and writes `data/raw/{station}_expo.qs`.
2. `data_analyses/traceplots_real_data.R` — run **interactively**. Inspect the
   traceplots, decide which chain to drop per gauge/likelihood (the choices are
   recorded in comments in that script), and write the retained chains as the
   `*_2chains.qs` objects that the log-likelihood scripts read.
3. `data_analyses/pred_task_real_data.R` — defines the station-specific
   prediction boxes and writes `data_analyses/pred_boxes.qs`, which
   `data_analyses/imp_samp_real_data_all_iter.R` reads.
